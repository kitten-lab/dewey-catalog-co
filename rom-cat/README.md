# ROM Cat

**SKU:** `CO.DCC-001-ROMCAT`  
**Maker:** Dewey Catalog Co. · `CO.DCC`  
**Path:** `ALICE_BOX/dewey-catalog-co/rom-cat/`

Catalog of **ROM producers** and their **ROM SKUs**.  
Built from DCO REQ: *REQ: DEWEY CATALOG CO SKU CAT-001*.

Open a producer → see ROMs → add / edit / remove. Incomplete ROMs allowed.

**Not** the sticky face at `cat-o-roms/` (keep that as art).  
**Not** a book.
